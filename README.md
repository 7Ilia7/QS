# Quality Service Hair Landing

Статический лендинг для салона Quality Service Hair, который продвигает услуги наращивания волос в Киеве. Сайт уже содержит ключевые блоки для первой версии: hero, видео-работы, описание студии, услуги, калькулятор стоимости, портфолио, отзывы, ориентировочные цены, преимущества, контактную форму и карту.

## Текущий стек

- HTML/CSS/JavaScript без сборщика.
- Локальные изображения в `img/`.
- Google Fonts: Inter и Playfair Display.
- Google Maps iframe.
- Отправка формы сейчас реализована напрямую через Telegram Bot API в `script.js`.

## Как открыть проект

Можно открыть `index.html` напрямую в браузере. Для более корректной проверки локально:

```powershell
python -m http.server 8000
```

Затем открыть:

```text
http://localhost:8000
```

## Что уже хорошо

- Есть полноценная структура лендинга с несколькими точками конверсии.
- Есть мобильное меню, lightbox для портфолио, калькулятор и плавные анимации.
- Используются локальные WebP изображения для большей части галереи.
- Контент уже сфокусирован на понятном бизнес-направлении: премиальное наращивание волос.
- Есть базовые SEO-теги, Open Graph и JSON-LD, которые можно довести до рабочего состояния.

## Что нужно улучшить в первую очередь

1. **Безопасность**
   - Убрать Telegram Bot token из `script.js`.
   - Сделать отправку заявок через backend, serverless function или CRM-интеграцию.
   - Добавить страницу политики конфиденциальности вместо `alert`.

2. **SEO и доверие**
   - Заменить `https://example.com/` на реальный домен.
   - Указать реальный телефон, адрес, график работы и ссылку на Google Business Profile.
   - Создать реальное изображение для `og:image`.
   - Добавить FAQ-разметку и расширить JSON-LD для локального бизнеса.

3. **Производительность**
   - Сжать `img/masteronwork.jpg` или заменить на WebP/AVIF.
   - Убрать preload на несуществующие `hero-dark.jpg` и `hero-dark@2x.jpg`.
   - Исправить битые `srcset` в услугах.
   - Удалить `.DS_Store` из репозитория и добавить `.gitignore`.

4. **Контент и конверсия**
   - Добавить реальные кейсы "до/после" с описанием длины, количества прядей, времени и цены.
   - Расширить отзывы: фото, источник, дата, ссылка на Instagram/Google.
   - Добавить FAQ: уход, коррекция, противопоказания, сроки носки, гарантия.
   - Сделать более конкретные CTA: консультация, расчет стоимости, запись в WhatsApp/Instagram.

5. **Техническое качество**
   - Разделить код на компоненты при переходе к полноценному сайту.
   - Добавить базовую проверку HTML/CSS и Lighthouse.
   - Добавить обработку ошибок формы и защиту от спама.

## Найденные конкретные проблемы

- `index.html` содержит `canonical`, `og:url` и JSON-LD с `example.com`.
- `og:image` указывает на `img/og-cover.jpg`, которого нет.
- `preload` hero указывает на `img/hero-dark.jpg`, которого нет.
- В `srcset` услуг есть ссылки на несуществующие `.jpg` версии и путь `img/poslugi/.IMG_1931.webp`.
- Видимый телефон `+38 (099) 041-9347` не совпадает с `tel:+380000000000` и JSON-LD.
- Внешние видео ведут на `nkstudio.com.ua`; нужно заменить на собственные материалы или подтвердить права.

## План развития по этапам

### Этап 1. Довести лендинг до стабильной версии

- Исправить битые ссылки на изображения и метаданные.
- Оптимизировать тяжелые изображения.
- Привести телефоны, адрес и соцсети к единому реальному набору данных.
- Убрать секреты из frontend.
- Добавить `.gitignore`.

### Этап 2. Усилить продажи

- Добавить блок FAQ.
- Добавить реальные отзывы и кейсы.
- Улучшить калькулятор: тип волос, желаемая длина, объем, коррекция, снятие.
- Сделать отправку заявки в Telegram/CRM через безопасный endpoint.
- Настроить цели аналитики: клик по телефону, Instagram, WhatsApp, отправка формы.

### Этап 3. Превратить лендинг в сайт

- Создать отдельные страницы:
  - `Наращивание волос`
  - `Коррекция`
  - `Снятие`
  - `Догляд`
  - `Портфолио`
  - `Цены`
  - `FAQ`
  - `Контакты`
  - `Блог`
- Добавить навигацию по услугам и внутреннюю перелинковку.
- Подготовить SEO-тексты под запросы: "наращивание волос Киев", "микрокапсульное наращивание", "коррекция нарощенного волосся".

### Этап 4. Перейти на современную платформу

- Рассмотреть Astro или Next.js для быстрого SEO-сайта.
- Вынести данные услуг, цен, отзывов и портфолио в JSON/CMS.
- Добавить админку или headless CMS для обновления работ и цен без правки кода.
- Подключить домен, SSL, аналитику, Search Console и sitemap.

### Этап 5. Развить бизнес-функции

- Онлайн-запись с календарем.
- CRM-воронка заявок.
- Автоматические напоминания клиентам.
- Личный кабинет или история процедур для постоянных клиентов.
- Блог/гайды по уходу для SEO и доверия.

## Рекомендуемое направление

Сначала стоит не переписывать проект полностью, а довести текущий лендинг до чистой, быстрой и безопасной версии. После этого лучше развивать его в полноценный сайт через отдельные SEO-страницы услуг и портфолио. Это даст больше органического трафика, больше доверия и более понятный путь клиента от просмотра работ до записи.
