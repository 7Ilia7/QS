# Шаблон scoped release / rollback

Це не дозвіл і не executable script. Заповнити за exact future owner handoff.

Чинний порядок QS від 02.11.2026: branch → local owner preview → explicit
chosen-version approval → релевантні QA/CI → merge/main → existing AUTO/server.
QA PASS і попередня blanket authority не є owner approval. Поточні три visual
options — LOCAL only; цей template не дозволяє push/PR/merge/deploy.

- Assignment / handoff / canonical executor / delivery / acceptance:
- Owner-approved site(s), environment, actions and prohibited effects:
- Source root/project/branch/commit; drift resolved; exact manifest SHA-256:
- Shown local preview URL/path, selected variant and exact previewed commit/digest:
- Explicit owner approval receipt/context for that version; changed bytes require renewed preview/approval:
- Independent review receipt + reviewed digest; secret scan limitations:
- Existing access/native permissions; no credential extraction:
- One writer; current remote link/artifact digest; shared-service baseline:
- Capacity/disk; scoped backup path+digest; unrelated routes preserved:
- Proposed release path and activation; candidate validation:
- Rollback target/digest, conditions and permitted operations:
- Uploaded / activated / verified timestamps and receipts (separate):
- HTTPS/cert/redirect/asset/PDF 200+206/hash and browser read-back:
- Telegram Reader / Mono Finance comparison, no real form submissions:
- Cleanup/remaining artifacts; Skipped / Blocked / Unknown:
- Uncertain effects and reconciliation; no blind retry:
- Same-handoff terminal result; CRM report/receipt; separate Telegram status:

Acceptance: truthful local readiness is not production readiness. A future release
cannot claim Completed/Passed from historical finals or file presence alone.
